# ⭐ Первые шаги на сервере

Поздравляем с подключением! Чтобы твоё начало игры было максимально комфортным, мы подготовили этот короткий гайд. Следуй по пунктам - и ты быстро освоишься!

---

### 👕 1. Настрой свой скин

Сразу после захода на сервер установи свой скин, чтобы другие игроки могли тебя узнать. Используй одну из команд:

* `/skin set <ник>` - загрузить скин по нику с Mojang
* `/skin url <ссылка>` - загрузить скин по прямой ссылке

> 💡 *Если ты берёшь ссылку из Discord, убедись, что она правильная. [Подробная инструкция по получению ссылки есть в разделе частых вопросов](common_questions).*

---

### 🤝 2. Присоединяйся к комьюнити

Наш сервер — это не только игра, но и уютное сообщество игроков. Обязательно присоединяйся к нашему [Discord-серверу](https://discord.gg/deQGEV8zwk).

В Discord тебя ждут:
* 🛟 Канал `🛟┃помощь`, всегда открытый для твоих вопросов и баг-репортов.
* 💬 Живое общение с другими игроками и администрацией.
* 📢 Эксклюзивные анонсы крупных обновлений и ивентов.

---

### ⌨️ 3. Основные команды

На сервере минимум команд - мы стараемся не перегружать интерфейс. Тебе достаточно знать всего две:

| Команда | Описание |
| :--- | :--- |
| `/hub` или `/spawn` | Телепортирует тебя на главный хаб сервера |
| `/menu` | Открывает главное меню сервера со всеми функциями |

---

### 🏆 4. Система престижа

Мы ценим время, которое ты проводишь с нами! За активную игру ты можешь получить **престиж** - специальный статус, дающий приятные бонусы.

Получить престиж можно через меню `/menu`. Всего доступно **три уровня**:

| Престиж | Требуемое время | Что даёт |
| :---: | :---: | :--- |
| **I** | 100 часов на сервере | 🎁 Базовые бонусы |
| **II** | 200 часов на сервере | ⚡ Расширенные бонусы |
| **III** | 500 часов на сервере | 👑 Максимальные награды и эксклюзивный контент |
