# 🟫 Табуреты

На нашем сервере добавлены **табуреты** - простая и практичная мебель без спинки. Они дешевле стульев и отлично подходят для быстрого обустройства дома. Крафтятся из любой породы дерева.

![Табуреты](/img/stools.png)

---

### 📊 Характеристики

| Параметр | Значение |
| :--- | :--- |
| **Прочность** | 3 удара |
| **Взаимодействие** | На них можно сидеть (ПКМ) |
| **Материалы** | Все породы дерева |

---

### 🪵 Как скрафтить табурет?

Табурет состоит из досок и палок. Можно использовать **любую породу дерева**.

⬜ ⬜ ⬜  
🪵 🪵 ⬜  
🦯 🦯 ⬜  

**Рецепт:**
* 🪵 2 × Любые обтёсанные брёвна
* 🦯 2 × Палка

**Результат:** 1 × Табурет из выбранного дерева
