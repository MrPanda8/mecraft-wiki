# 🦋 Набор: Бабочки

На нашем сервере добавлены **бабочки**! Они порхают в разных биомах, и ты можешь ловить их, коллекционировать и использовать для украшения своего дома.

![Бабочки в банках](/img/butterflies.png)

---

### 🌍 Виды бабочек и где их найти

В мире существует **8 видов бабочек**, каждая из которых обитает в своих биомах. Все бабочки спавнятся **только днём на поверхности** при ясной погоде.

| Вид бабочки | Биомы обитания |
| :--- | :--- |
| 🌼 **Луговая** (`meadow`) | Равнины, Подсолнечные равнины, Луга |
| 🌳 **Лесная** (`forest`) | Лес, Цветочный лес, Березовый лес, Старый березовый лес |
| 🌴 **Джунглевая** (`jungle`) | Джунгли, Разреженные джунгли, Бамбуковые джунгли |
| 🦁 **Саванновая** (`savanna`) | Саванна, Саванное плато |
| 🐸 **Болотная** (`swamp`) | Болото, Мангровое болото |
| 🌸 **Вишнёвая** (`cherry`) | Вишнёвая роща |
| 🌲 **Таёжная** (`taiga`) | Тайга, Старая сосновая тайга, Старая еловая тайга |
| ✨ **Золотая** (`golden`) | 🌤️ **Аэриум**: Небесные луга, Золотая роща |

:::info
Важно: в радиусе 64 блока может быть только **одна бабочка** каждого вида.
:::

### 📊 Характеристики бабочек

| Параметр | Значение |
| :--- | :--- |
| **Здоровье** | 2 HP (1 сердце) |
| **Опыт за убийство** | 0 |
| **Деспавн** | Ночью, в дождь и при контакте с водой |

:::tip
Если ты хочешь, чтобы бабочка **не деспавнилась**, назови её **биркой**. После этого она останется в мире навсегда, даже ночью и в дождь.
:::

### 🎣 Как поймать бабочку?

Для ловли тебе понадобятся два предмета: **Сачок** и **Пустая банка**.

#### 1️⃣ Скрафти сачок

⬜ 🧵 🧵  
⬜ 🪙 🧵  
🪵 ⬜ ⬜  

**Рецепт:**
* 🧵 3 × Нить (`minecraft:string`)
* 🪙 1 × Медный слиток (`minecraft:copper_ingot`)
* 🪵 1 × Палка (`minecraft:stick`)

**Результат:** 1 × Сачок (`mecraft:butterfly_net`)

#### 2️⃣ Скрафти пустую банку

⬜ 🪵 ⬜  
🟦 ⬜ 🟦  
⬜ 🟦 ⬜  

**Рецепт:**
* 🟦 3 × Стекло (`minecraft:glass`)
* 🪵 1 × Любые доски (`#minecraft:wooden_tool_materials`)

**Результат:** 1 × Пустая банка (`mecraft:empty_jar`)

#### 3️⃣ Поймай бабочку!

1. Найди бабочку.
2. Возьми в руку **Сачок** (`mecraft:butterfly_net`).
3. Нажми **ПКМ** по бабочке - она окажется в банке!

---

### 🏺 Универсальность пустой банки

Пустая банка `mecraft:empty_jar` - это не просто тара для бабочек. У неё есть два отличных дополнительных применения:

* 🖼️ **Мини-витрина:** Если поставить пустую банку на пол, внутрь можно положить **1 любой предмет**. Это отличный способ красиво отобразить редкие находки, трофеи или ключевые предметы!
* ⛑️ **Необычный шлем:** Пустую банку можно **надеть на голову**.

### 🦋 Как использовать бабочек?

#### 🎨 Декорация

Банку с бабочкой можно поставить на пол. Она будет красиво выглядеть и создавать уютную атмосферу в твоём доме.

#### 🦋 Выпустить бабочку

Если ты хочешь выпустить бабочку обратно в мир:

1. Положи **банку с бабочкой** в верстак (в любое место).
2. Забери результат - бабочка появится **на месте игрока**, а пустая банка вернётся в инвентарь.

### 💡 Советы и интересные факты

* ✨ **Золотая бабочка** - самая редкая, так как обитает только в Аэриуме. Отправься в райское измерение, чтобы поймать её!
* 🌸 **Вишнёвая бабочка** выглядит особенно красиво на фоне цветущих вишнёвых деревьев.
* 🏠 **Создай коллекцию:** собери все 8 видов бабочек и выстави их у себя дома.
