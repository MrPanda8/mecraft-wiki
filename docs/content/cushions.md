# 🛋️ Подушки

На нашем сервере добавлены **подушки** - мягкая мебель всех 16 цветов! Они отлично подходят для создания уютных зон отдыха.

![Подушки](/img/cushions.png)

---

### 📊 Характеристики

| Параметр | Значение |
| :--- | :--- |
| **Прочность** | 1 удар |
| **Взаимодействие** | На них можно сидеть (ПКМ) |
| **Особенность** | Можно ставить друг на друга |
| **Цвета** | Все 16 цветов шерсти |

---

### 🧶 Как скрафтить подушку?

Подушки крафтятся из **шерстяных плит**. Каждый цвет даёт подушку соответствующего цвета.

⬜ ⬜ ⬜  
⬜ ⬜ ⬜  
🧶 🧶 🧶  

**Рецепт:**
* 🧶 3 × Шерстяная плита нужного цвета

**Результат:** 1 × Подушка соответствующего цвета

:::tip
Чтобы получить шерстяную плиту, положи 3 шерстяных блока в ряд - получится 6 плит.
:::
