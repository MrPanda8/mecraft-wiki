# 🌤️ Аэриум - Райское измерение

Аэриум - это загадочное и прекрасное измерение, парящее в небе. Здесь нет твёрдой земли под ногами - только летающие острова, покрытые уникальной растительностью и населённые необычными существами.

---

### 📊 Технические характеристики

| Параметр | Значение |
| :--- | :--- |
| **Высота мира** | 256 блоков |
| **Тип генерации** | Летающие острова |
| **Способ попадания** | Через портал |

---

### 🌿 Биомы Аэриума

В измерении представлено **5 уникальных биомов**, каждый со своей атмосферой и ресурсами:

| Биом | ID | Описание |

| **Небесные луга** | `mecraft:sky_meadows` | 🌼 Светлые поляны с яркими цветами |

| **Инеевая небесная тайга** | `mecraft:frosted_sky_taiga` | ❄️ Заснеженные сосны и снег |
