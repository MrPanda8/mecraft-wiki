# 🖍️ Мелки

На нашем сервере добавлены **мелки** - цветные мелки для создания узоров на поверхностях! Отлично подходят для навигации, меток и творчества.

![Мелки в действии](/img/chalks.png)

---

### 📊 Характеристики

| Параметр | Значение |
| :--- | :--- |
| **Количество цветов** | 16 |
| **Типы** | Обычные и светящиеся |
| **Узоры** | 8 вариантов |
| **Смена узора** | Прямо в инвентаре через крафт |
| **Прочность метки** | 1 удар (стирается) |
| **Размещение** | Пол, стены, потолок |

:::info
Мелки рисуют узоры на любых поверхностях. Светящиеся мелки видны в темноте, но не излучают настоящий свет.
:::

![Светящиеся мелки в пещере](/img/glowing_chalks.png)

:::tip
Светящиеся мелки - отличный способ отметить путь в пещерах или создать светящиеся узоры для декора!
:::

---

### 🎨 Узоры

У каждого мелка есть **8 вариантов узоров**. По умолчанию мелок рисует стрелку, но ты можешь менять его прямо в инвентаре!

| ID | Название | Описание |
| :--- | :--- | :--- |
| `arrow` | Стрелка | Указывает направление |
| `cross` | Крест | Крестообразный узор |
| `skull` | Череп | Узор в виде черепа |
| `home` | Дом | Узор в виде дома |
| `exclamation_mark` | Восклицательный знак | Для важных меток |
| `question_mark` | Вопросительный знак | Для загадочных мест |
| `dashed_line` | Пунктир | Пунктирная линия |

---

### 🧪 Как скрафтить обычные мелки?

Обычные мелки крафтятся из кальцита и красителя.

⬜ ⬜ ⬜  
⬜ 🪨 🎨   
⬜ ⬜ ⬜  

**Рецепт:**
* 🪨 1 × Кальцит
* 🎨 1 × Краситель любого цвета

**Результат:** 8 × Мелок выбранного цвета

---

### ✨ Как скрафтить светящиеся мелки?

Светящиеся мелки требуют дополнительный ингредиент - светящийся чернильный мешок.

⬜ ⬜ ⬜  
🪨 🎨 🦑    
⬜ ⬜ ⬜  

**Рецепт:**
* 🪨 1 × Кальцит
* 🎨 1 × Краситель любого цвета
* 🦑 1 × Светящийся чернильный мешок

**Результат:** 8 × Светящийся мелок выбранного цвета

---

### ⚠️ Важно

- Мелки рисуют узоры **на любых поверхностях** - пол, стены, потолок.
- Метки **стираются за 1 удар** - будь осторожен, не сотри их случайно!
- **Светящиеся мелки** видны в темноте, но не освещают окружающие блоки.
- Узоры меняются **циклически** через крафт в инвентаре.
- Мелки можно **ломать и перерисовывать** - они не привязаны к месту навсегда.
