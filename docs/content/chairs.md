# 🪑 Стулья

На нашем сервере добавлены **стулья** - уютная мебель, на которой можно сидеть! Крафтятся из любой породы дерева, что позволяет подобрать идеальный вариант под интерьер твоего дома.

![Стулья](/img/chairs.png)

---

### 📊 Характеристики

| Параметр | Значение |
| :--- | :--- |
| **Прочность** | 3 удара |
| **Взаимодействие** | На них можно сидеть (ПКМ) |
| **Материалы** | Все породы дерева |

---

### 🪵 Как скрафтить стул?

Стул состоит из досок и палок. Можно использовать **любую породу дерева**.

🪵 ⬜ ⬜  
🪵 🪵 ⬜  
🦯 🦯 ⬜ 

**Рецепт:**
* 🪵 3 × Любое обтёсанное бревно
* 🦯 2 × Палка

**Результат:** 1 × Стул из выбранного дерева
