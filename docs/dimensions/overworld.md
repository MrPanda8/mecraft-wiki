# 🎨 Переработка цветов биомов

Мы переработали цвета неба и воды в Overworld, чтобы каждый биом имел свою уникальную атмосферу.

---

### 🌍 Изменения по биомам

| Биом | Небо | Вода |
| :--- | :--- | :--- |
| 🌵 **Жаркие биомы** (пустыня, саванна) | Желтоватый оттенок | Стандартная |
| ❄️ **Холодные биомы** (тундра, горы) | Бледное | Стандартная |
| 🌴 **Джунгли** | Яркое, насыщенное | Тёмная |
| 🐸 **Болота** | Зеленоватое | Стандартная |
| 🌸 **Вишнёвая роща** | Розовое | Стандартная |
| 🍄 **Грибные острова** | Фиолетовое | Фиолетовая |
