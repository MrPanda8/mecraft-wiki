# 🔥 Сгорание блоков

На нашем сервере огонь оставляет следы: сгоревшие блоки превращаются в **обгоревшие версии** или **пепел**.

![Демонстрация пожара](/img/block-burning.png)

---

### ⚙️ Как это работает?

Когда огонь достигает деревянного блока:
1. Блок превращается в **обгоревшую версию** (сохраняет форму)
2. Листья с шансом **25%** превращаются в **пепел**

---

### 📋 Таблица превращений

| Исходный блок | После сгорания |
| :--- | :--- |
| 🪵 Брёвна | Обгоревшее бревно |
| 🪵 Обтёсанные брёвна | Обтёсанное обгоревшее бревно |
| 🌳 Древесина | Обгоревшая древесина |
| 🌳 Обтёсанная древесина | Обтёсанная обгоревшая древесина |
| 🪵 Доски | Обгоревшие доски |
| 🪵 Плиты | Обгоревшая плита |
| 🪵 Ступеньки | Обгоревшие ступеньки |
| 🍃 Листья | Пепел |
