# 📦 Контент

Наш сервер - это не просто ванильный Minecraft. Мы добавляем уникальный контент, который меняет игру, сохраняя при этом её классическую атмосферу. 

Всё, что мы добавляем, организовано в **тематические наборы**. На этой странице ты найдёшь ссылки на полные гайды по каждому из них, где собраны все связанные предметы, блоки и мобы.

---

### 💡 Как пользоваться этим разделом?

1. Выбери интересующий тебя набор из таблицы выше.
2. На странице набора ты найдёшь **полный гайд**: как получить предметы, как их использовать и какие свойства они имеют.

:::tip
Мы постоянно расширяем контент! Если у тебя есть идея для нового набора предметов или блоков, обязательно предложи её в нашем [Discord-сервере](https://discord.gg/deQGEV8zwk).
:::
