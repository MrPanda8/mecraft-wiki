# 🔥 Сгорание блоков

На нашем сервере реализована новая механика взаимодействия огня с деревянными блоками. Теперь когда блок загорается, он **не исчезает бесследно**, а превращается в обгоревшую версию или пепел. Это добавляет реализма пожарам и открывает новые возможности для строительства!

![Демонстрация пожара](/img/block-burning.png)

---

### ⚙️ Как это работает?

Когда огонь распространяется на деревянный блок, происходит одно из двух:
1. Блок **превращается в обгоревшую версию** (сохраняя форму и тип блока)
2. Листья с шансом **25% превращаются в пепел**

---

### 📋 Таблица превращений

| Исходный блок | После сгорания |
| :--- | :--- |
| 🪵 Любое бревно | Обгоревшее бревно |
| 🪵 Любое обтёсанное бревно | Обтёсанное обгоревшее бревно |
| 🌳 Любая древесина | Обгоревшая древесина |
| 🌳 Любая обтёсанная древесина | Обтёсанная обгоревшая древесина |
| 🪵 Любые доски | Обгоревшие доски |
| 🪵 Любые плиты | Обгоревшая плита |
| 🪵 Любые ступеньки | Обгоревшие ступеньки |
| 🍃 Любые листья | Пепел *(шанс 25%)* |

:::tip
Если твой деревянный дом загорелся, он не исчезнет полностью! Вместо этого ты получишь обгоревшие версии тех же блоков, которые можно использовать для строительства.
:::
